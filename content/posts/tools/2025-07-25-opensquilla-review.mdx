OpenSquilla는 동일한 토큰 예산에서 더 높은 지능 밀도를 끌어내는 마이크로커널 방식의 AI 에이전트 프레임워크다.

## 무엇을 해결하나

LLM 기반 에이전트를 운영하다 보면 토큰 소비가 비용과 직결된다. 복잡한 태스크를 수행할수록 컨텍스트 윈도우가 빠르게 소진되고, 여러 도구를 호출할 때마다 불필요한 토큰이 누적된다. OpenSquilla는 스마트 라우팅, 영속 메모리, 보안 샌드박스, 내장 웹 검색, 로컬 임베딩을 하나의 모델 루프 안에 통합해 이 문제를 정면으로 공략한다. Web UI, CLI, 채팅 채널 등 모든 진입점이 공유 `TurnRunner`를 거치기 때문에 실행 경로가 단일화되어 토큰 낭비를 구조적으로 줄인다.

## 핵심 기능 3가지

**1. SquillaRouter — 스마트 라우팅**
번들된 라우터가 요청의 복잡도와 특성에 따라 최적의 LLM 프로바이더를 자동 선택한다. OpenRouter, OpenAI, Anthropic, Ollama, DeepSeek, Gemini, Qwen/DashScope 등 약 20개 이상의 프로바이더를 코드나 설정 스키마 변경 없이 전환할 수 있다. 저비용 모델로 충분한 요청은 저비용 모델로, 고난도 추론이 필요한 요청만 대형 모델로 보내는 식이다.

**2. 영속 메모리(Persistent Memory)**
대화 컨텍스트를 세션 간에 유지하면서도 불필요한 토큰 재전송을 최소화한다. 에이전트가 이전 대화에서 학습한 내용을 다음 턴에서 압축된 형태로 재활용하므로, 긴 대화에서도 토큰 소모가 선형적으로 증가하지 않는다.

**3. 보안 샌드박스 + 내장 웹 검색**
코드 실행과 웹 검색을 별도 프로세스 격리 환경에서 처리한다. 외부 도구 호출 시 보안 경계를 유지하면서도 단일 에이전트 루프 안에서 모든 작업이 완결된다.

## 설치 및 사용 예시

소스에서 설치하는 방법이 현재 권장 경로다.

```bash
# 사전 요구사항: Git, Git LFS, uv
# macOS (Homebrew 사용 시)
brew install git git-lfs uv
git lfs install

# 레포 클론 및 설치
git clone https://github.com/opensquilla/opensquilla.git
cd opensquilla
uv sync

# 실행
opensquilla --provider openai --model gpt-4o
```

Windows PowerShell 환경이라면 아래처럼 사전 도구를 설치한다.

```powershell
winget install --id Git.Git -e
winget install --id GitHub.GitLFS -e
powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/install.ps1 | iex"
git lfs install
```

라우터를 의도적으로 비활성화하려면 `--router disabled` 옵션을 추가한다.

## 누구에게 유용한가

- **LLM API 비용을 절감하고 싶은 팀**: 스마트 라우팅으로 모델별 단가 차이를 자동 활용할 수 있다.
- **다중 프로바이더를 유연하게 전환해야 하는 개발자**: 설정 변경 없이 20여 개 프로바이더를 넘나든다.
- **에이전트 기반 자동화 파이프라인을 구축하는 경우**: CLI, Web UI, 채팅 채널 모두 동일한 TurnRunner를 공유하므로 배포 형태에 구애받지 않는다.
