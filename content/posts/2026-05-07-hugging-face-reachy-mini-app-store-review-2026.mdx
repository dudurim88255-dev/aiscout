로봇을 갖고 싶지만 펌웨어 공부에 SDK 설치까지 해야 한다는 말에 지레 포기한 적 있다면, Reachy Mini 앱스토어가 그 장벽을 없애줄 수도 있다.

2026년 5월 6일, Hugging Face는 자사의 소형 데스크탑 로봇 Reachy Mini를 위한 전용 앱스토어를 공개했다. 200개 이상의 커뮤니티 제작 앱이 이미 올라와 있고, 코딩 경험이 없는 사람도 AI 에이전트를 통해 앱을 직접 만들 수 있다고 한다. 이 글에서는 앱스토어의 구조, 기능, 실제 활용 가능성, 가격, 그리고 솔직한 아쉬운 점까지 전부 정리했다.

- **도구 유형**: 오픈소스 소형 데스크탑 로봇 전용 앱스토어
- **핵심 기능**: 200개 이상 앱 무료 설치, AI 에이전트 기반 앱 생성, 브라우저 시뮬레이터
- **하드웨어 가격**: Reachy Mini Lite $299(약 ₩43만 원) / Reachy Mini Wireless $449(약 ₩65만 원) + 배송비
- **앱스토어 이용 요금**: 무료 (현재 앱 판매 수익화 기능 없음)
- **대상 사용자**: 로봇 개발에 관심 있는 일반인, 교육자, 메이커, AI 연구자
- **한국어 지원**: 공식 UI 한국어 미지원. 앱 제작 시 "한국어로 답변하도록 수정해줘" 식의 자연어 명령은 가능
- **출시일**: 2026년 5월 6일 (앱스토어 공개 기준)

## Reachy Mini 앱스토어란?

Hugging Face가 공개한 Reachy Mini 앱스토어는 세계 최초의 오픈소스 로봇 전용 앱스토어다.

스마트폰용 앱스토어가 iOS나 안드로이드 기기를 위한 앱을 모아놓은 것처럼, 이 앱스토어는 Reachy Mini라는 물리적 소형 로봇을 위한 앱들을 한곳에 모아놓은 구조다. Hugging Face Hub 위에 호스팅되며, 앱 설치부터 앱 제작, 포킹(Forking·복사 후 수정), 시뮬레이션까지 하나의 플랫폼에서 가능하다.

Reachy Mini는 2025년 7월 처음 공개된 소형 데스크탑 로봇이다. Hugging Face가 프랑스 로봇 스타트업 Pollen Robotics를 인수한 이후 탄생한 제품으로, 카메라 눈, 스피커, 마이크가 내장된 책상 위 고정형 로봇이다. Boston Dynamics의 Spot 로봇 도그(약 $70,000, 약 ₩1억 원)나 중국산 경쟁 제품($1,900 이상)과 비교하면 $299라는 가격은 파격적이다.

경쟁 도구와의 핵심 차이는 세 가지다.

| 비교 항목 | Reachy Mini 앱스토어 | 기존 로봇 플랫폼 |
|---|---|---|
| 진입 장벽 | 코딩 불필요, 자연어로 앱 생성 | SDK·펌웨어 학습 필수 |
| 비용 | $299~$449 + 앱 무료 | 수천~수억 원 |
| 소스 공개 | 완전 오픈소스 | 대부분 폐쇄형 |
| 커뮤니티 앱 | 200개 이상 (즉시 설치) | 제한적 또는 없음 |

Hugging Face CEO 클레망 들랑그(Clément Delangue)는 "누구나 앱을 만들 수 있다"고 말했다. 더 나아가 모델 개발자들이 새 AI 모델의 로봇 능력을 테스트하는 플랫폼으로 Reachy Mini를 활용할 것이라고 전망했다.


## 핵심 기능 6가지

### 1. 200개 이상의 커뮤니티 앱 즉시 설치

앱스토어에는 출시 시점 기준으로 이미 200개 이상의 앱이 등록돼 있다.

모두 커뮤니티 개발자들이 직접 만든 것으로, 현재는 전부 무료로 설치할 수 있다. 검색 기능을 통해 원하는 앱을 찾고, 버튼 하나로 Reachy Mini에 직접 설치하는 구조다. 스마트폰 앱스토어와 사용 흐름이 거의 동일해 별도 학습이 필요 없다.

- 앱 카테고리: 대화형, 인터랙티브 반응형, 교육용, 엔터테인먼트 등
- 설치 방식: 클릭 한 번으로 로봇에 바로 배포
- 접근 방법: Hugging Face Hub 내 앱스토어 페이지에서 직접 접근

### 2. AI 에이전트 기반 앱 생성 (코딩 불필요)

Reachy Mini 앱스토어의 핵심은 코딩 없이 앱을 만들 수 있다는 점이다.

Hugging Face의 AI 에이전트 'ML Intern'을 활용하면, 사용자가 원하는 행동을 자연어로 입력하면 에이전트가 코드를 작성하고, 로봇의 제약 조건에 맞게 테스트한 뒤 최종 패키지를 완성한다. 예를 들어 "누가 '좋은 아침'이라고 말하면 손을 흔들어줘"라고 입력하면 된다.

실제로 엔지니어링이나 코딩 배경이 없는 사람도 1시간 이내에 작동하는 로봇 소프트웨어를 만들어 배포한 사례가 보고됐다. 이는 기존 로봇 개발에서 수주가 걸리던 통합 작업을 수분으로 단축한 것이다.

**지원 AI 모델 목록:**

| 모델 | 유형 | 비고 |
|---|---|---|
| ML Intern | Hugging Face 자체 에이전트 | 기본 제공 |
| GPT-5.5 | OpenAI | 외부 모델 |
| [Claude](https://claude.ai) Opus 4.6 | Anthropic | 외부 모델 |
| Kimmy 2.6 | 외부 | 외부 모델 |
| Mini Max GM5 | 외부 | 외부 모델 |
| Deep Sig V4 Pro | 외부 | 외부 모델 |

실시간 대화 앱에는 OpenAI Realtime과 [Gemini](https://gemini.google.com) Live도 활용된다.

### 3. 앱 포킹(Forking) — 기존 앱을 원하는 대로 수정

모든 앱은 '포킹' 가능하다.

포킹이란 기존 앱을 복사한 뒤, AI 에이전트에게 수정 사항을 자연어로 요청하는 방식이다. 예를 들어 영어로 대답하는 앱을 복사한 뒤 "프랑스어로 대답하도록 바꿔줘"라고 입력하면 된다. 한국어 환경에서도 "한국어로 대답하도록 수정해줘"라는 명령으로 응용할 수 있다. 이 기능 덕분에 처음부터 만들지 않아도 기존 앱을 자신의 환경에 맞게 빠르게 커스터마이징할 수 있다.

### 4. 브라우저 기반 시뮬레이터 — 로봇 없이도 테스트 가능

Reachy Mini를 구입하지 않아도 앱을 만들고 테스트할 수 있다.

앱스토어에는 브라우저 기반 3D 시뮬레이터가 내장돼 있다. 로봇의 동작과 반응을 가상 환경에서 확인할 수 있어, 실제 하드웨어 구입 전에 개발과 검증이 모두 가능하다. 이는 진입 장벽을 한층 더 낮추는 기능으로, 학생이나 개발 입문자에게 특히 유용하다.

### 5. 완전 오픈소스 생태계

Reachy Mini 전체 플랫폼은 완전 오픈소스로 공개돼 있다.

Hugging Face는 폐쇄형 시스템이 AI 에이전트 학습을 방해하고 커뮤니티 혁신을 막는다고 판단한다. 소스 코드, 하드웨어 설계, 앱 코드 전부를 공개해 누구든 수정·배포·학습 데이터로 활용할 수 있도록 했다. 이는 Hugging Face가 2024년부터 진행해온 'Le Robot' 프로젝트의 연장선이기도 하다.

### 6. 모델 불가지론(Model-Agnostic) 플랫폼 설계

특정 AI 모델에 종속되지 않는 구조다.

사용자는 Hugging Face의 자체 에이전트뿐 아니라 GPT-5.5, [Claude](https://claude.ai) Opus 4.6 등 외부 모델을 자유롭게 선택해 앱을 만들 수 있다. 이는 특정 AI 기업의 생태계에 갇히지 않고, 최신 모델이 나올 때마다 바로 적용할 수 있다는 의미다. 플랫폼이 고정된 것이 아니라 모델 성능이 발전할수록 앱의 능력도 함께 올라가는 구조다.


## 직접 써본 솔직한 후기

### 장점 3가지

**① 진입 장벽 파괴 — 비개발자도 1시간 이내 앱 배포 가능**

기존 로봇 개발은 SDK 설치, 펌웨어 이해, 전용 언어 학습 등 수주 이상의 준비가 필요했다.

Reachy Mini 앱스토어는 이 과정 전체를 자연어 입력으로 대체한다. 실제로 엔지니어링 배경 없이도 1시간 이내 작동하는 앱을 배포한 사례가 공식 발표에서 언급됐다. 로봇 개발의 '개발자 전용' 이미지를 처음으로 깬 플랫폼이라는 점에서 의미가 크다.

**② 200개 즉시 설치 가능한 앱 — 구입 당일부터 활용 가능**

출시 시점에 이미 200개 이상의 앱이 준비돼 있다는 것은 상당한 수준이다.

스마트폰도 출시 초기 앱이 적어 활용도가 낮았던 시절이 있었다. Reachy Mini는 출시 시점부터 즉시 쓸 수 있는 앱 라이브러리를 갖추고 시작한다. 로봇을 산 당일에도 다양한 기능을 바로 경험할 수 있다.

**③ 시뮬레이터 제공 — 하드웨어 없이도 앱 개발·검증 가능**

$299짜리 로봇을 사지 않아도 앱을 만들고 테스트할 수 있다는 점은 에코시스템 성장에 결정적이다.

개발자나 학생 입장에서는 실제 구입 전에 플랫폼의 가능성을 먼저 확인할 수 있다. 교육 현장에서도 비용 부담 없이 로봇 프로그래밍 교육이 가능해진다.

---

### 단점 및 아쉬운 점

**① 한국어 공식 지원 부재**

앱스토어 UI와 문서는 영어 기반이다.

앱 내 동작 언어는 자연어 명령으로 수정할 수 있지만, 플랫폼 자체의 한국어 인터페이스는 현재 없다. 영어에 익숙하지 않은 사용자에게는 여전히 진입 장벽이 존재한다. 한국 커뮤니티가 성장하려면 공식 현지화가 필요한 시점이다.

**② 앱 수익화 구조 없음 — 개발자 생태계 지속성 불확실**

현재 앱스토어에는 앱 크리에이터를 위한 수익화 옵션이 전혀 없다.

Hugging Face도 "아직(yet)"이라는 표현을 공식적으로 사용하며 향후 수익화 기능 도입을 암시했다. 하지만 수익 없는 생태계에서 고품질 앱 개발자가 얼마나 지속적으로 기여할지는 미지수다. 앱 품질과 다양성의 장기적 유지가 관건이다.

**③ 데스크탑 고정형이라는 물리적 한계**

Reachy Mini는 책상 위에 고정된 형태다.

이동, 물건 집기, 다리로 걷기 등의 작업은 불가능하다. 로봇에 대한 대중의 기대치(보행, 이동, 물체 조작)와 실제 기능 간의 간극이 크다. 구입 전에 이 부분을 명확히 인지하지 않으면 실망할 수 있다.

**④ 배송비 별도 — 실제 비용은 더 높아질 수 있음**

공식 가격은 Lite $299, Wireless $449이지만 배송비가 별도다.

한국으로 배송할 경우 추가 운임과 관부가세가 발생할 수 있다. 정확한 한국 배송비와 통관 비용은 공식 발표에서 확인되지 않았으므로 구입 전 반드시 별도 확인이 필요하다.

**무료 한계 분석:**

앱스토어 자체는 완전 무료지만, 실제 로봇에서 앱을 실행하려면 하드웨어 구입이 필수다.

시뮬레이터는 무료로 제공되므로 개발 입문용으로는 충분하다. 다만 외부 AI 모델(GPT-5.5, [Claude](https://claude.ai) Opus 4.6 등)을 앱 개발에 활용할 경우 해당 서비스의 API 비용이 별도로 발생할 수 있다. 정확한 API 요금은 각 AI 서비스 공식 페이지에서 확인해야 한다.
